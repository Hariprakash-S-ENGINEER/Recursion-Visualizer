How does recursion work?

Let's find 3! (3 factorial) by letting a function call itself.

THE IDEA

A function solving a smaller version of the same problem

Example: factorial(3)
factorial(3)=3 × 2 × 1=6
WATCH THE CALL STACK
CALL 1 factorial(3) 3 × factorial(2) waiting…
CALL 2 factorial(2) 2 × factorial(1) waiting…
CALL 3 factorial(1) Base case: return 1 base case!
RETURN2 × 1 = 2
RETURN3 × 2 = 6
Calls go down ↓ Answers come back ↑
1

Call itself

factorial(3) asks for factorial(2). Then 2 asks for 1.

2

Stop condition

factorial(1) reaches the base case and returns 1.

3

Return answers

The waiting calls finish: 2 × 1 = 2, then 3 × 2 = 6.

THE CODE

Just a few lines

JavaScript-style pseudocode 
function factorial(n) {
  if (n === 1) {
    return 1;       // base case
  }

  return n * factorial(n - 1); // recursive call
}

factorial(3); // result: 6
Remember: Recursion needs a base case to stop, and each call should move closer to it.
